# 🎮 SAMP Android Lua Scripts

Collection of custom Lua scripts for **SA-MP (San Andreas Multiplayer) Android** using **MoonLoader**.

---

## 📦 Scripts Available

### 1. **Custom HUD** (`CustomHUD.lua`)

Minimalist and modern custom HUD replacement with full configuration panel.

#### ✨ Features:
- 🩸 **Health Bar** - Progress bar with customizable colors
- 🛡️ **Armor Bar** - Progress bar display
- 💰 **Money Display** - Formatted with thousand separators
- 🔫 **Weapon & Ammo** - Current weapon with ammo count
- ⭐ **Wanted Level** - Star display (★★★★★)
- 🕐 **Time** - In-game time display
- 📍 **Location** - Current zone/area name

#### ⚙️ Configuration Panel:
- **Position Sliders** - Adjust X & Y position for each element
- **Scale Control** - Resize elements (0.5x - 2.0x)
- **Color Picker** - RGBA color customization
- **Enable/Disable** - Toggle individual elements
- **Progress Bars** - Optional for Health & Armor
- **Real-time Preview** - See changes instantly
- **Auto-save** - Config saved to `CustomHUD.ini`

#### 🎯 Usage:
1. Copy `CustomHUD.lua` to MoonLoader folder
2. In-game, type `/chud` to open config panel
3. Adjust position, colors, and settings
4. Click **SAVE CONFIG** to save changes

---

## 📥 Installation

### Requirements:
- GTA SA Android (v2.00 recommended)
- **MoonLoader** installed
- **mimgui** library
- **inicfg** library

### Steps:
1. Download the script you want
2. Copy to: `/sdcard/Android/data/com.rockstargames.gtasa/moonloader/`
3. Restart game or reload scripts
4. Use the command to access config (e.g., `/chud`)

## 🛠️ Configuration

All scripts save their configuration to `.ini` files in the MoonLoader directory.

**CustomHUD.lua** → `CustomHUD.ini`

You can manually edit these files or use the in-game config panels.

## 🎨 Customization

### Custom HUD Colors:
- Red Health: `RGB(255, 50, 50)`
- Silver Armor: `RGB(200, 200, 200)`
- Green Money: `RGB(50, 255, 50)`
- Gold Weapon: `RGB(255, 200, 50)`

Colors can be changed via the in-game color picker!
